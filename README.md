# حارس العلامة (Brand Guard) — Full Brand Protection Suite

تطبيق ويب متكامل لحماية العلامات التجارية ورصد الحسابات والمواقع المنتحلة، ثنائي اللغة (**عربي RTL** + **English LTR**)، في ملف واحد بدون أي مكتبات خارجية أو خطوات بناء.
يعمل محلياً بالكامل (IndexedDB) ويدعم التثبيت والعمل بدون إنترنت (PWA) مع خيار مزامنة سحابية مجانية عبر Supabase.

## التشغيل (Running the App)
- **النسخة العربية (مع زر تبديل فوري للإنجليزية `EN`)**: افتح `index.html` أو `hares-alalama.html`.
- **النسخة الإنجليزية المباشرة (English Default)**: افتح `brand-guard-en.html` (أو أضف `?lang=en` للرابط).
- على الهاتف أو الكمبيوتر: افتح الرابط ثم اختر **«إضافة إلى الشاشة الرئيسية» (Install App)** ليعمل كتطبيق مستقل حتى بدون إنترنت.

## منظومة الحماية الكاملة للعميل (Full Protection Features)

1. **خمسة أنواع حالات مع تعرّف ذكي وختم أدلة قانوني (Forensic Evidence Watermark)**:
   - أنواع الحالات: حساب تواصل، موقع/نطاق، رقم/قناة (واتساب، تيليجرام)، إعلان مدفوع، إعلان في متجر.
   - **ختم الأدلة الزمني**: عند إرفاق لقطات الشاشة، يختم التطبيق تلقائياً شريط توثيق قانوني أسفل الصورة يحتوي على (`UTC Timestamp + Target URL + Brand Name`) لتقديمها كدليل رسمي.
   - حفظ **رقم البلاغ المرجعي (`#Ref ID`)** الصادر من المنصة لكل حالة لسهولة المتابعة والتصعيد.

2. **روابط النماذج الرسمية المباشرة + مولّد البلاغات القانونية (عربي / English)**:
   - يولّد نص البلاغ القانوني مخصصاً لنوع الانتحال والمنصة مع رقم تسجيل العلامة التجارية ورقم الرخصة والروابط الرسمية.
   - أزرار فتح مباشرة لنماذج **انتهاك العلامة التجارية (Trademark Form)** و**انتحال الهوية (Impersonation Form)** لكل من Instagram وFacebook وTikTok وX وSnapchat وYouTube وTelegram وWhatsApp.

3. **كاشف بيانات مسجّل النطاق والاستضافة (Live Whois / RDAP & Abuse Inspector)**:
   - لأي موقع أو نطاق منتحل، يفحص التطبيق بروتوكول `RDAP` مباشرة من المتصفح لكشف الشركة المسجّلة للنطاق (Registrar)، تاريخ التسجيل، خوادم الأسماء (Nameservers)، وبريد الإبلاغ عن الانتهاكات (`Abuse Email`).
   - زر بضغطة واحدة لمراسلة `Abuse Email` الخاص بمسجّل النطاق لطلب تعليق الموقع من المصدر.

4. **مولّد بطاقة تحذير العملاء للستوري (1080×1920 Scam Alert Story Card)**:
   - بضغطة واحدة داخل أي حالة، ينشئ التطبيق صورة عالية الدقة (`1080×1920 PNG`) جاهزة للنشر في Instagram Story أو حالة WhatsApp لتحذير العملاء من الحساب/الموقع المنتحل مع إبراز القنوات الرسمية المعتمدة للعلامة.

5. **مركز التصعيد للجهات الرسمية (UAE • KSA • Global Escalation Center)**:
   - روابط تصعيد مباشرة مع زر طباعة ملف شكوى PDF للحالة:
     - **الإمارات (UAE)**: شرطة دبي (`eCrime.ae`)، اقتصادية دبي وحماية المستهلك (`consumerrights.ae`)، هيئة تنظيم الاتصالات (`tdra.gov.ae`).
     - **السعودية (KSA)**: الهيئة السعودية للملكية الفكرية (`saip.gov.sa`)، هيئة الاتصالات والفضاء والتقنية لحجب المواقع (`cst.gov.sa`)، وزارة التجارة (`mc.gov.sa`).
     - **عالمي (Global)**: Google Safe Browsing (تحذير المتصفحات)، Cloudflare Abuse (كشف وإيقاف الاستضافة)، ICANN Compliance.

6. **تبويب «الفحص الاستباقي» (`Scan`)**:
   - روابط **Meta Ad Library** باسم العلامة (الإمارات / السعودية / كل الدول).
   - **فحص النطاقات المشابهة (DNS Lookalike Scanner)**: بديل `dnstwist` داخل المتصفح عبر Cloudflare DNS-over-HTTPS لكشف النطاقات المشابهة المسجّلة فعلياً مع زر تسجيل فوري كحالة.
   - فحص عكسي لصور المنتجات عبر **Google Lens** و**TinEye**.
   - بحث سريع في جوجل داخل المنصات، وتنويعات اسم الحساب الرسمي مع قائمة تدقيق.

7. **فحص توفّر الروابط (Link Liveness Checker) وتنبيهات التأخير**:
   - يفحص ما إذا كان الرابط أو النطاق المنتحل قد أُزيل (`NXDOMAIN` / متوقف) مع زر لتحديث حالته إلى «أُزيل».
   - إشعارات متصفح وملخص فوري عبر **واتساب** و**البريد الإلكتروني** للبلاغات المتأخرة.

8. **نموذج بلاغات العملاء (`?report=1`)، أدوار المستخدمين (`مالك / موظف`)، وعرض تجريبي جاهز (`Client Demo Preset`)**:
   - رابط عام للعملاء للإبلاغ عن الحسابات المشبوهة مع وسم `بلاغ عميل`.
   - وضع موظف محمي برمز PIN للمالك.
   - زر **«تحميل بيانات العرض التجريبي»** في الإعدادات لاستعراض النظام بالكامل أمام أي عميل بضغطة واحدة.
